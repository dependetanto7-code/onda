Passo a passo

Como instalar

Leva menos de um minuto. Escolha a versão que você baixou:

  1. Baixe o arquivo Onda-Setup-v1.0.exe. Se o navegador disser que o arquivo “não é baixado com frequência”, escolha Manter.
  2. Abra o arquivo baixado (ele fica na pasta Downloads).
  3. Se aparecer “O Windows protegeu o computador”, clique em Mais informações e depois em Executar assim mesmo.
  4. Siga o instalador. Quando terminar, é só abrir o Onda e dar play.

O aviso azul do Windows é comum em programas novos e independentes. Baixe sempre por esta página para ter o arquivo original.

  1. Baixe o arquivo Onda-Portable-v1.0.exe.
  2. Coloque o arquivo onde quiser: na área de trabalho, numa pasta ou num pendrive.
  3. Dê dois cliques para abrir. Nada é instalado no computador.
  4. Clique com o botão direito no arquivo e escolha Extrair tudo.
  5. Abra a pasta extraída e dê dois cliques no Onda. Nada é instalado no computador.
  6. Se aparecer “O Windows protegeu o computador”, clique em Mais informações → Executar assim mesmo.

Dica: guarde o portable num pendrive e use o Onda em qualquer PC com Windows.

  1. No celular, toque em Baixar APK. Está no PC? Use o .
  2. Se o navegador avisar que o arquivo pode ser perigoso, confirme que quer baixar.
  3. Abra o arquivo Onda-v1.0.apk: ele aparece nas notificações ou em Arquivos › Downloads.
  4. Se o Android pedir permissão, toque em Configurações, ative Permitir desta fonte e volte.
  5. Toque em Instalar. Se o Play Protect mostrar um aviso, toque em Mais detalhes → Instalar mesmo assim.
Dúvidas

Perguntas frequentes

Instalador ou portable: qual eu escolho?
Na dúvida, fique com o instalador: ele coloca o Onda no seu PC como um programa normal. O portable abre direto do arquivo, sem instalar nada. É bom para pendrive ou para computadores onde você não tem permissão para instalar programas.
Por que o Windows avisa que o app é desconhecido?
O Windows mostra a tela “O Windows protegeu o computador” para programas novos, que ainda são baixados por pouca gente ou não têm certificado de assinatura digital. Para abrir, clique em Mais informações → Executar assim mesmo. Baixe sempre por esta página para ter o arquivo original.
Tenho iPhone ou Mac. Dá para usar?
Ainda não tem versão para iPhone, iPad ou Mac. Mas dá para usar o Onda direto no navegador: INDISPONIVEL.
Como atualizar para uma versão nova?
Volte a esta página e baixe de novo: ela sempre mostra a versão mais recente. No PC, é só instalar a versão nova; no Android, instale o APK novo por cima do antigo.
Precisa de internet?
Sim. O Onda busca as músicas, as letras e os vídeos pela internet enquanto você ouve.
